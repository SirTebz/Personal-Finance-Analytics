# Analytics

Savings rate = `(total income - total expenses) / total income × 100`. Zero-income ranges return 0%. Average monthly values divide totals by the months containing selected transactions. Category distribution is a category's expense divided by total expenses. Results are descriptive only and are not financial advice.

The `database/queries/financial_analysis.sql` file demonstrates aggregation, joins, conditional expressions, CTEs, subqueries, date functions, and window functions against the SQL Server schema.
